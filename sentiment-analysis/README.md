# Sentiment Analysis

A scikit-learn based sentiment analysis notebook using the movie reviews
dataset (`movie_reviews.csv`).

- `sentiment_1.ipynb` — exploratory/modelling notebook.
- `movie_reviews.csv` — dataset used for training and evaluation.

## Usage

Open `sentiment_1.ipynb` in Jupyter and run the cells:

```bash
jupyter notebook sentiment_1.ipynb
```
